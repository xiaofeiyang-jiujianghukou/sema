# 路线图

> 原则：每个里程碑结束时都有**可演示、可收费验证**的东西；先跑通商业闭环，再拓宽内容面。

## M0 · 骨架与钱包（起手 1–2 周）

**目标**：技术地基 + 商业模式的地基（积分账本）落地。

- Monorepo 脚手架：`apps/mobile`(Expo) / `apps/api`(Fastify) / `packages/{shared,ai-core,db}`
- 登录：手机号验证码（微信/Apple 登录排 M2）
- 钱包核心：注册送体验积分、充值（先接沙箱/人工通道）、账本、账单页
- 价目表 v1 落在 `packages/shared`，账单页可真实展示每笔明细
- CI：lint + test + 类型检查；部署脚本打通（api → 国内云）

**验收**：手机上装 App，注册即有余额，账单页看到赠送记录，账目对得上。

## M1 · 核心体验：AI 口语陪练（3–4 周）

**目标**：把「值回价签」的那一分钟做出来。

- ai-core：LLM/ASR/TTS 抽象层 + 首批供应商（方舟或百炼起步）+ 成本埋点
- 语音对话全链路流式（首字 < 1.5s），打断（barge-in）
- 3 个精品情景（中→英）：咖啡店点单 / 求职面试 / 旅行问路；AI 角色化、难度自适应
- 按分钟计费接入：对话前明示单价、结束出账单（消费 + 收获同屏）

**验收**：真实用户完成一次 10 分钟对话，付费扣账正确，复盘报告「下次开口就能用」。

### M1 交付进度（2026-09-28）

- ✅ ai-core 抽象层：LLM 流式统一接口 + OpenAI 兼容适配器（方舟/百炼/OpenAI 三通）+ CostMeter 成本埋点 + 任务分级路由（11 tests）
- ✅ 3 个精品情景（中→英）内容资产 + 质量门槛测试
- ✅ 会话服务 + **按秒累进计费**（水表模型：每个 turn/end 结清秒段、幂等、余额不足即时拦截）接入钱包（29 tests，全链路冒烟通过）
- ✅ 语音传输 → **M1.5 已完成**（方舟语音 + WS 实时管线 + 真实冒烟）
- ⏳ 复盘报告 → M2（与生词本一起做，先有 SRS 落点再出报告）

## M1.5 · 语音传输与真机联调（1–2 周）✅ 服务端完成

**目标**：把 M1 的文本回路升级为真·开口说话。

- ✅ ai-core 语音抽象：`TTSProvider` / `ASRProvider` + 方舟 plan 通道适配器
  （二进制帧协议编解码 8 tests；Mock 实现零成本测试）—— 19 tests
- ✅ 方舟语音实测打通：TTS（seed-tts-2.0）+ ASR（seedasr bigmodel，en-US 提示）
  真实回路验证——TTS 合成的英文，ASR 逐词转写正确（AFP 按秒计费）
- ✅ WS `/v1/realtime` 双通道协议 + VAD 断句 + barge-in（6 tests）—— api 35 tests 全绿
- ✅ 真实语音 WS 冒烟：真 Key 全链路（TTS 上行 → ASR → turn 计费 → TTS 下行）通过
- ⏳ 真机联调：iPhone / 安卓各一台，端到端延迟达标（首字 < 1.5s）→ M2 前置
- 实测协议要点沉淀在 architecture.md §7.3（RIFF 头、序号从 2、累积快照、语言提示等）

**验收（服务端部分）**：Mock 全链路 63 tests 全绿 + 真实语音端到端冒烟通过；
真机部分待 M2 移动端壳一起做。

## M2 · 学习闭环与档案（2–3 周）✅ 领域层完成

**目标**：终身学习的第一块砖——今天学的，下周还回得来。

- ✅ 复盘报告：真实 LLM 结构化输出（纠错/地道说法/生词提取/亮点重点），
  zod 严格校验 + 幂等计费（1 积分/次）；真实冒烟通过（doubao-mini 套餐通道）
- ✅ 生词本 + FSRS-5 复习（ts-fsrs 封装 + 8 个调度不变量测试）；
  复盘生词自动入本、手动添加、到期队列、打分推进
- ✅ 生词 AI 精讲：廉价档按需生成（释义/例句/辨析/记忆钩子/搭配），
  每词一次缓存终身，10厘/词幂等计费；真实冒烟通过
- ✅ 学习档案：时长/开口/词汇增长/连续天数/14 天曲线 + 全量数据导出
- ✅ 供应商通道矩阵沉淀：平台 /api/v3 与套餐 /api/plan/v3 双通道实测通过
- ⏳ 微信 / Apple 登录（需开放平台应用凭证，待移动端壳一起做）
- ⏳ Postgres 仓储（@sema/db）替换内存实现（接口已就绪，随部署一起）

**验收（领域层）**：73 tests 全绿；真实闭环冒烟——对话→复盘→生词入本→
精讲→到期队列→档案统计全链路通过。隔天复习的产品验收待登录与移动端。

## M3 · 收费验证（2 周 + 运营持续）

**目标**：让陌生人真金白银付费，验证单位经济学。

- 正式支付：iOS IAP + 微信/支付宝；定价校准（真实成本报表 → 调价）
- ✅ 内容扩到 10 情景（中→英手写打磨）× 3 语言对抽象（中→日/中→韩试点
  已全链路真冒烟，余量以 scenario_pack 内容包扩容）
- 应用商店提审（前置：移动端壳 + 微信/Apple 登录）
- 内测 50–200 人：付费转化率、单用户毛利、次周留存、延迟达标率
- 合规收尾：ICP 备案、隐私政策、语音数据删除通道

**验收**：存在「第三次充值」的用户——按量付费模式成立的最硬证据。
