# 命名档案：说嘛 Sema

> 定名时间：M0 期间。原则：**抖音/TikTok 式命名逻辑**——名字是产品体验里的那个声音/动作，双语同源（不是翻译），极短，普世音素，听到即懂。

## 定名逻辑

1. **名字即动作**：滴滴→车来了，钉钉→消息来了，抖音→抖起来；我们的产品动作 = 开口说
2. **双语同源**：抖音/TikTok 是同一个声音的两种拼法；国内国外感觉一致
3. **极短 + 普世音素**：2 音节、s/m/a 级别的基础音，任何语言母语者零门槛
4. **躲开品类词**：speak / voice / talk / mute / mic 已被 2025 年 AI 浪潮挤爆，做不了品牌脸

## 定名：Sema × 说嘛

- **Sema**：斯瓦希里语「说吧！」——非洲使用人数最多的语言里，开口说就是这个音
- **说嘛**：中文口语「想说就说嘛」——把按量付费的零压力哲学写进名字
- 两者都是 2 音节、/s_m_a/ 结构、口语祈使语气——同源双生
- 检索无同品类消费产品占用（2026-09 检索）
