# 产品蓝图

> 状态：v0.1（MVP 规划版）｜所有定价数字为设计锚点，上线前用真实成本校准。

## 1. 目标用户

首发面向**中国学习者学外语**（中→英为主锚点，中→日等按架构平铺扩展）；架构上语言对（`source_lang × target_lang`）完全参数化，未来可零改动支持外国人学中文。

典型画像：

- **通勤党**：每天 10–15 分钟，想开口说但没对象练
- **备考/出国党**：口语面试、雅思托福、留学生存对话
- **兴趣党**：追番学日语、旅行前突击，使用有波峰波谷——**正是按量付费最服务的场景**（订阅制下他们是最先流失的人群，在我们这里他们是回头客）

## 2. 商业模式：积分制按量付费

**预充值积分，余额永久有效，消费透明可查。**

- 充值买积分（如 ¥1 = 10 积分），积分不过期
- 所有消耗动作明码标价，见下方价目表
- 每笔消费进账单：时间、动作、单价、数量、扣减积分——**让用户像看电费单一样看学习账单，这是信任的来源**
- 免费额度：新用户送少量体验积分（够 1–2 次完整对话），体验完自然转化

### 价目表（设计锚点）

| 动作 | 计价 | 说明 |
|---|---|---|
| AI 口语对话 | 按分钟（如 3 积分/分钟） | 核心付费点；开始前明示单价，结束出账单 |
| 对话复盘报告 | 按次 | 纠错、替代表达、生词提取 |
| 生词 AI 精讲 | 按词 | 例句、辨析、记忆钩子 |
| 情景课程包 | 按包解锁 | **内容资产化**：预生成、边际成本≈0、毛利最高 |

### 平台支付的现实约束

- **iOS**：数字商品必须走 Apple IAP（小型开发者计划 15% 抽成）——积分充值在 iOS 走 IAP，定价需覆盖抽成
- **Android/国内渠道**：微信支付 / 支付宝，抽成低
- 策略：两端同价、积分到账一致，抽成差异计入整体毛利模型，不对用户搞双轨价（伤害信任）

## 3. 核心体验：一次对话的完整闭环

```
选情景 → 明示单价 → 开口对话（ASR→LLM→TTS 流式）
       → 结束 → 复盘报告（纠错/更地道说法/生词）
       → 生词自动入 SRS 复习队列 → 档案沉淀（时长/词汇/进步曲线）
```

设计要点：

1. **30 秒内开口**：打开 App 到说上第一句话，不超过 30 秒。学习者的敌人是启动成本
2. **AI 会带戏**：不是问答机器人，是有角色、有目标、会犯人类的错（语速、口音、打断）的对话者；难度随用户水平自适应
3. **复盘是口碑核心**：不复述对话，只给「下次开口就能用的改进」——3 个纠错 + 3 个更地道的说法 + 生词卡
4. **账单时刻即品牌时刻**：对话结束同时展示「本次消费」和「本次收获」，用户觉得值，付费才可持续

## 4. MVP 范围（In / Out）

**In：**

- 手机号 / 微信 / Apple 登录
- 钱包：充值、余额、账单明细、消费透明
- 3 个首发语言对：中→英（主）、中→日、英→中；每对 10 个精选情景
- 语音对话 + 复盘报告 + 生词本（FSRS 复习）
- 学习档案页：累计时长、开口次数、词汇增长、历史复盘

**Out（MVP 明确不做）：**

- 打字聊天、语法课、考试真题、社区、排行榜、多端同步之外的社交功能

## 5. 差异化与护城河

1. **商业模式本身**：按量付费对「低频/波动用户」是碾压性友好，这批人被订阅制伤过
2. **成本工程**：多模型路由 + 内容资产化，让同样质量的单分钟成本比友商低 → 可以定价更低或毛利更厚
3. **学习档案复利**：FSRS + 口语史 + 弱点画像，用得越久越懂你，迁移成本越高

## 6. 关键风险

| 风险 | 应对 |
|---|---|
| iOS IAP 抽成侵蚀毛利 | 定价模型预留 15% 空间；引导安卓端充值 |
| 语音链路延迟毁体验 | 全链路流式；延迟 >1.5s 即视为事故级指标 |
| AI 输出质量波动 | 抽象层支持 A/B 与快速回滚；复盘模板强约束输出结构 |
| 合规（ICP/增值电信、语音数据隐私） | 部署在国内云；语音默认仅用于本次服务，明确告知、可删除；上线前完成备案审查 |
